# 買い物リスト — プライバシーポリシーとサポート

iPhone アプリ「買い物リスト」の、App Store に登録する 2 つの URL を公開するためのリポジトリ。
アプリ本体のリポジトリとは別にしてある。`shirube-privacy` と同じ形。

| App Store Connect の欄 | URL | ファイル |
| --- | --- | --- |
| プライバシーポリシー URL | https://suu-u522.github.io/shopping-todo-privacy/ | `index.html` |
| サポート URL | https://suu-u522.github.io/shopping-todo-privacy/support/ | `support/index.html` |

リポジトリ名を変えると**公開済みの URL が変わる**。提出後は変えないこと。

## 書き方の方針

**一般の利用者が、ぱっと見て分かる長さにとどめる。** 保存しているキーの名前や使っている
フレームワークまで並べない。ポリシーで読む人が知りたいのは「自分の買い物リストが外に
出るのか」の 1 点で、そこだけ確実に伝わればよい。技術的な詳細は本体リポジトリの
`docs/spec/06-data-model.md` にある。

サポートのほうは、App Store の説明文（本体の `docs/store/app-store-ja.md`）と同じことを
書いている。**説明文を直したらこちらも直す。** 食い違うと、ストアで読んだ説明とサポートの
案内が違うことになる。

## 広告について書いていない理由

**将来広告を入れる予定があるため、「広告なし」をうたわない。**

一度「広告なし」と書くと、入れたときに約束を破ったことになる。ポリシーもストアの説明文も
書き換えが要るうえ、低評価の理由になる。言わなければ、入れたときに直すのはポリシーの
追記だけで済む。同じ理由で「通信なし」「オフライン」も書いていない（広告 SDK は通信する）。

**広告を入れるときは、このページに広告の節を足し、App Store の「App のプライバシー」
申告も見直すこと。** 広告 SDK は識別子を取るので、「データを収集しません」では通らなくなる。
関連する実装は本体の `Sources/ShoppingTodo/Views/Main/AdSlotView.swift`（いまは空）。

## 内容の正・写しの関係

**実装が正で、このページはその写し。** 保存するものが変わったら、先に本体を直してから
このページを更新する。

## 日本語と英語を併記している理由

App Review の担当者が日本語話者とは限らない。データを収集しないことを英語でも読めるようにしてある。
サポートのほうは日本語のみ（アプリ自体が日本語のみのため）。
